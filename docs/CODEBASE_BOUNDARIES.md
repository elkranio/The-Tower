# Карта кода The Tower

Актуализировано по `master` на 2026-11-12. Правила границ остаются в `AGENTS.md`.

Это **граница ответственности**, а не предложение переместить файлы. p34t используем как есть; сейчас его не перерабатываем.

## Игровая область — здесь работаем

| Путь | Назначение |
| --- | --- |
| `src/app/scenes/game/Game.ts` | Запускает магазин с тремя слоями (`bg`, `cards`, `ui`) и пассивные продажи. |
| `src/app/scenes/game/ShopSalesController.ts` | Выбор товара, движение иконок на прилавок, оплата, уход покупателя. |
| `src/app/scenes/game/view/ShopView.ts` | Оформление магазина, слоты товара, анимация денег. |
| `src/app/scenes/game/view/CustomerLoopView.ts` | Появление, движение и уход покупателей; запускает баббл перед продажей. |
| `src/app/scenes/game/view/CustomerBubbleView.ts` | Rex BBCodeText: одна тестовая реплика, цвет, fade слов, динамический баббл. |
| `src/app/scenes/game/LootTinderController.ts` | Отдельный v0 прототип свайпов, сейчас не подключён к сцене магазина. |
| `src/app/scenes/game/**` | Прочие игровые представления, контроллеры и конфигурация прототипов. |
| `src/app/game/GameSession.ts`, `itemCatalog.ts` | Состояние склада/прилавка/денег и каталог 15 предметов. |
| Новые модули внутри `src/app/` | Игровые правила, состояние, данные, UI и другие конкретно игровые вещи, **когда понадобятся**. Структуру не создавать заранее. |
| `assets/raw/**` | Исходные изображения и звуки для пайплайна. |
| `assets/live/**` | Рабочие ассеты, которые приложение загружает через `public/assets`. Существующие демо-ассеты не менять без задачи. |

## p34t и инфраструктура — не трогаем по умолчанию

| Путь | Что там лежит |
| --- | --- |
| `src/system/**` | `AudioManager`, `LayerManager`, `StorageManager`, `ScreenWakeLock`, `Utils`. |
| `src/components/**` | Общие UI-примитивы `Button`, `Cover`, `Fade`. Это библиотека p34t, не место для игровых виджетов. |
| `src/utils/**` | Адаптивный масштаб и ориентация экрана. |
| `src/app/scenes/BaseScene.ts` | Базовая сцена с `LayerManager` и отложенным `start()`. |
| `src/app/scenes/boot/**` | Системный Boot. |
| `src/types/**` | Глобальные расширения типов Phaser и Spine. |
| `scripts/**`, `deploy/**` | Упаковка атласов/звука, копирование ассетов и старый деплой. |
| `vite.config.mjs`, `tsconfig.json` | Конфигурация сборки/TypeScript. |

Для использования допустимо прочитать API этих модулей. Их изменение или рефакторинг — отдельное решение, не побочный эффект игровой задачи.

| Файл | Разрешённый тип изменений |

## Пайплайн ассетов и команды

`assets/raw` → (`npm run pack:tex` / `npm run pack:sfx`) → `assets/live` → (`npm run copy:live`) → `public/assets` → приложение.

- `npm run dev` и `npm run build` **сначала запускают `copy:live`**, удаляя содержимое `public/assets` и копируя туда `assets/live`. Правки в `public/assets` потеряются.
- В стартовом коммите `public/assets` закоммичен вместе с `assets/live`, но это не делает его первоисточником.
- `npm run deploy` **не запускать**: `deploy/deploy.js` указывает на сторонний старый FTP-путь и использует `deleteRemote: true`.
- В `package.json` пока нет отдельных `typecheck`/`test` команд. Если нужно проверить TS, использовать `npx tsc --noEmit`; сборка — `npm run build` с учётом копирования ассетов.

## Актуальные особенности

- Текущая сцена — пассивные продажи; Loot Tinder v0 лежит в коде отдельно и не связан с `GameSession`.
- `assets/live/fonts/rubik.ttf` — локальный Web Font для бабблов. BBCodeText подключён через `phaser3-rex-plugins` (без замены Phaser).
- Аудиоспрайт `sfx` загружается в `Preload.ts` с параметром версии на JSON/OGG/MP3, а проигрывание клика защищено проверкой кеша.
- Текущий запас товара и баланс тестовые; UI перекладывания склада на прилавок, оптовиков и игрового дня пока нет.
