## Игровая область — здесь работаем

| Путь | Назначение |
| --- | --- |
| `src/app/scenes/game/Game.ts` | Единственная пока игровая сцена; сейчас задаёт слои `bg`, `player`, `ui` и выводит лог. |
| `src/app/scenes/game/**` | Развитие текущей сцены, игровые представления и взаимодействия. |
| Новые модули внутри `src/app/` | Игровые правила, состояние, данные, UI и другие конкретно игровые вещи, **когда понадобятся**. Структуру не создавать заранее. |
| `assets/raw/**` | Исходные изображения и звуки для пайплайна. |
| `assets/live/**` | Рабочие ассеты, которые приложение загружает через `public/assets`. Существующие демо-ассеты не менять без задачи. |

## p34t и инфраструктура — не трогаем по умолчанию

| Путь | Что там лежит |

| `src/components/**` | Общие UI-примитивы `Button`, `Cover`, `Fade`. Это библиотека p34t, не место для игровых виджетов. |

| `src/app/scenes/BaseScene.ts` | Базовая сцена с `LayerManager` и отложенным `start()`. |
| `src/app/scenes/boot/**` | Системный Boot. |
| `src/types/**` | Глобальные расширения типов Phaser и Spine. |
| `scripts/**`, `deploy/**` | Упаковка атласов/звука, копирование ассетов и старый деплой. |
| `vite.config.mjs`, `tsconfig.json` | Конфигурация сборки/TypeScript. |

Для использования допустимо прочитать API этих модулей. Их изменение или рефакторинг — отдельное решение, не побочный эффект игровой задачи.

## Пайплайн ассетов и команды

`assets/raw` → (`npm run pack:tex` / `npm run pack:sfx`) → `assets/live` → (`npm run copy:live`) → `public/assets` → приложение.

- `npm run dev` и `npm run build` **сначала запускают `copy:live`**, удаляя содержимое `public/assets` и копируя туда `assets/live`. Правки в `public/assets` потеряются.
- В стартовом коммите `public/assets` закоммичен вместе с `assets/live`, но это не делает его первоисточником.
- `npm run deploy` **не запускать**: `deploy/deploy.js` указывает на сторонний старый FTP-путь и использует `deleteRemote: true`.
- В `package.json` пока нет отдельных `typecheck`/`test` команд. Если нужно проверить TS, использовать `npx tsc --noEmit`; сборка — `npm run build` с учётом копирования ассетов.

## Наблюдения без задачи на исправление

- В `p34t.options.ts` пока шаблонные название и префикс, ориентация — `portrait`; настройка под игру будет отдельным маленьким изменением.
- В `Preload.ts` пока загружаются демо-музыка, шрифты и атлас p34t.
- Никакой отдельной игровой модели, симуляции или UI The Tower пока нет. Не навязывать архитектуру до первой конкретной механики.
