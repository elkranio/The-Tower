# The Tower

Mobile-first (9:16) fantasy shop game. Phaser 3 + TypeScript + p34t.

## Сейчас работает

- Магазин с прилавком 5×4, тестовым ассортиментом и балансом. Каталог содержит 15 предметов; расходники стакаются, экипировка хранится по экземплярам.
- 10 типов посетителей: приходят по одному, произносят тестовую реплику и автоматически покупают 1–4 доступные единицы товара. Иконки собираются на поверхности перед посетителем; затем единая оплата, анимация баланса и `+N`.
- Баббл покупателя: локальный Rubik, Rex BBCodeText, цветное выделение, проявление по словам и пауза для чтения. Пока у всех одна реплика про кладбище.
- Loot Tinder v0 существует отдельно в коде, но **не включён** в текущую сцену магазина и **не связан** с общим складом/деньгами.

Это проверенные отдельные прототипы, **ещё не полный игровой цикл**.
