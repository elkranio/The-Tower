# The Tower

Mobile-first (9:16) fantasy shop game. Phaser 3 + TypeScript + p34t.

## Куда смотреть

- [`AGENTS.md`](AGENTS.md) — правила работы с репозиторием: границы изменений, формат `.patch`, проверки.
- [`docs/CODEBASE_BOUNDARIES.md`](docs/CODEBASE_BOUNDARIES.md) — карта игрового кода, защищённой инфраструктуры и ассетного пайплайна.
- [`docs/SHOP_LOOP_V0.md`](docs/SHOP_LOOP_V0.md) — **актуальный согласованный план магазинного цикла** и следующих атомов. Это дизайн-спецификация, не список уже реализованных фич.
- [`handoff.md`](handoff.md) — краткий технический handoff, если был заполнен. Не заменяет дизайн-документ.

## Для нового coding chat / агента

1. Прочитать `AGENTS.md` и `docs/CODEBASE_BOUNDARIES.md`.
2. Для работы над магазином прочитать `docs/SHOP_LOOP_V0.md`.
3. Сверить документацию с **актуальным кодом** `src/app/scenes/game/**` и текущим `master`.
4. Делать только запрошенный небольшой атом; неподтверждённые будущие идеи не реализовывать.

Главный приоритет: построить минимальный полный магазинный цикл вокруг уже работающего Loot Tinder.

Новые дизайн-документы добавлять в `docs/` и ссылаться на них отсюда.
